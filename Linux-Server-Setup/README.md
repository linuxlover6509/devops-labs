# Linux Server Setup

This repository contains a set of Ansible roles for automated deployment and configuration of Debian-based servers.

The project provides a baseline server setup including user management, SSH hardening, firewall configuration, automatic updates, time zone configuration, and basic security tooling such as Fail2Ban.

It is intended to be used as a reproducible and consistent infrastructure bootstrap for new servers in development and production environments.

This project is part of [roadmap.sh](https://roadmap.sh/projects/linux-server-setup) DevOps projects.
